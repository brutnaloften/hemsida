## Hand-corrected reasoning

`write-reasoning` would overwrite a hand-written text with the cached model text, which happened once to tido-ungdomskriminalitetsnamnder. Corrected texts are therefore pinned: `write-reasoning --only <id> --pin <id> --text "..."` validates the text (`reasoningProblems`), stores it in `tools/out/reasoning-cache` under the promise's prompt key and records it with that key in `tools/reasoning-pins.json`. Every run re-applies the pins whose key still matches, so a rerun reproduces them; if the evidence changes the key changes, the pin is reported as stale and the model writes a new text. Pinned: tido-ungdomskriminalitetsnamnder (original text restored), tido-juridiskt-stod-brottsoffer, tido-starkt-straffrattsligt-skydd-poliser, tido-oversyn-kamerabevakningslagen, tido-anmalningsplikt-skolor-brott, tido-forbjud-kusinaktenskap, tido-missbruk-uppehallstillstand-studier, tido-forlangd-preskription-utvisningsbeslut, tido-minska-lararnas-administrativa-bordan, tido-langsiktiga-strukturer-utsatta-omraden-bid, tido-oversyn-brottsskadeersattning-skadestand, tido-inskrank-permission, tido-aterfall-straffas-hardare. Two SFS notes derived from the judge were wrong and fixed at their source (the judge result's `missing_sv`, then re-applied): SFS 2024:70 (a false claim about the proposition year) and SFS 2025:220 (claimed municipal rights were not shown, although the permit requirement is removed generally).
