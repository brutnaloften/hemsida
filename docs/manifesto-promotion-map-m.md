# Moderaterna 2022 manifesto promotion map

Candidates in `src/data/2022-2026/candidates/valmanifest-2022-m.json` are kept as the record of the extraction and the proposed links. The promotion was done by a one-off script (the shared promote tool is hard-wired to L; see the follow-up bead) that prepends one `agreement` evidence entry for `tidoavtalet` (2022-10-14) to each candidate.

256 candidates became 256 promises in `src/data/2022-2026/promises/` (`val2022-m-*.json`). Review was done by AI in place of a human reviewer, as decided for seeding. Verdicts are unchanged: every promise is `unassessed`, except the 4 `vague` ones, which are `not_assessable`. Outcome labels describe the agreement text only and are not verdicts.
